# Adapt a post for a platform

The same idea needs a different shape on each platform. Write each as its own post; never paste one text on all three.

- **X:** at most 280 characters, counting every character and any link. One sharp sentence or two. No thread unless the task asks for one, and a thread is several separate posts, each its own proposal.
- **LinkedIn:** up to 3,000 characters. A first line that stands alone, short paragraphs, a plain tone. A specific example beats a general claim.
- **Instagram:** up to 2,200 characters for the caption, and it needs an image or video, which a text-only post cannot give. Say in your comment that an image is needed; do not propose a text-only Instagram post.

If a proposal is refused as too long, cut words, not meaning: drop the least important sentence. Do not split a post to dodge a limit, and do not change the facts to make it fit.
